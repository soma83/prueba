# React + TypeScript + Vite


## Instalación

### Prerequisitos

- **Node.js** ≥ 18
- **pnpm** ≥ 8 (se puede instalar con `corepack enable pnpm` o `npm install -g pnpm`)

### Inicio rápdido

```bash
# Clonar el repositorio
git clone <your-repo-url>
cd prueba

# Instalar dependencias
pnpm install

# Iniciar el servidor de desarrollo
pnpm dev
```
